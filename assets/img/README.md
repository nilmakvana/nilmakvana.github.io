# Images

Drop a photo of yourself in here (e.g. `nil.jpg`, roughly square, 800×800 or larger).

Then in `index.html` replace **both** occurrences of

    https://avatars.githubusercontent.com/u/78582368?v=4

with

    assets/img/nil.jpg

There are two: one in the hero and one in the About section.
Until then the site falls back to your GitHub avatar, which works fine.
