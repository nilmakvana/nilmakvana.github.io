I rebuilt Git from scratch 🧩

Most of us type git commit every day without knowing what happens next. MyGit is my answer to that — a version control system written from zero in C++ that reimplements Git’s real object model: blobs, trees and commits, hashed with actual SHA-1 and compressed with actual zlib.

No framework, no shortcuts, no dependencies beyond the standard library. Just a small, inspectable codebase where the magic stops being magic.
